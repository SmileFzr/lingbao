# 无限回响：生肖灵宝

一个纯前端的回合制抓宠 + 大世界探索小游戏。**零依赖、零构建**，打开 `index.html` 就能玩。

- 十二生肖灵兽 + 五行相克
- 5 个区域的大世界（草原 / 森林 / 沙漠 / 海洋 / 废墟）
- 回合制战斗、捕捉、升级、图鉴
- 每个区域深处都有一位**区域霸主**

## 怎么玩

| 操作 | 说明 |
| --- | --- |
| 拖动屏幕 | 移动（左下虚拟摇杆） |
| 靠近目标点按钮 | 进入建筑 / 进洞 / 和 NPC 说话 |
| 左下小地图 | 点开**世界地图** |
| 世界地图 | 点任意位置标记 → 选「走过去」或「传送过去」 |
| 右下按钮 | 🚶 自动探索 · 🎒 背包 · 👥 队伍 · 🏠 回村 |

### 大世界

以青石村为中心的五个区域，走出去会自动切换背景与 BGM：

| 区域 | 位置 | 建筑 | 特点 |
| --- | --- | --- | --- |
| 🌾 青草原 | 中心 | 🌬️ 风车小屋 | 安全区，青石村所在地 |
| 🌲 迷雾森林 | 北 | 🛖 树屋营地 | 树木密集，野生灵兽偏木系 |
| 🏜️ 流沙荒漠 | 东 | 🏕️ 沙商驿站 | 沙丘与仙人掌，偏火/土系 |
| 🌊 碧潮之海 | 南 | 🗼 海崖灯塔 | **走进去脚下会出现小船 🛶**，偏水系 |
| 🏚️ 灰烬废墟 | 西 | 🏯 残破塔楼 | 断墙与骸骨，偏土/金系 |

每座建筑都能交谈：客栈类可以回血，商店类可以直接买卖；每个区域还有一位 NPC 提供治疗与线索。

### 特殊地点与霸主

每个区域有一个可以钻进去的地点，往里走到底会遇上**区域霸主**：

| 区域 | 特殊地点 | 霸主 |
| --- | --- | --- |
| 青草原 | 🗿 荒原祭坛 | 🐃 蛮角王 |
| 迷雾森林 | 🌳 古树洞 | 🌳 千年树妖 |
| 流沙荒漠 | 🔺 流沙金字塔 | 🏺 法老王 |
| 碧潮之海 | 🚢 沉船海窟 | 🐋 利维坦 |
| 灰烬废墟 | 🕳️ 石头山洞 | 💀 骸骨王 |

打赢（或抓到手）会记录讨伐进度，并奖励**传说灵气球**。霸主也能被捕捉，但成功率低得多。

## 目录结构

```
index.html        入口（只负责 DOM 结构）
css/style.css     全部样式
js/data.js        五行/技能/灵兽/道具/区域/地点/NPC/BOSS 数据
js/audio.js       8-bit 音乐合成器（各区域不同曲目）
js/core.js        存档、toast、界面切换
js/world.js       区域判定、小地图与大地图、寻路与传送
js/explore.js     探索主循环、场景装饰、交互
js/cave.js        洞窟内部与霸主触发
js/battle.js      回合制战斗、捕捉、结算
js/ui.js          面板与按钮绑定
tests/smoke.js    Node 冒烟测试（无需浏览器）
```

加载顺序不能随意改：`data → audio → core → world → explore → cave → battle → ui`。

## 开发

跑一遍冒烟测试（会用 DOM 桩把整局游戏逻辑真实跑一遍）：

```bash
node tests/smoke.js
```

覆盖：5 区域判定、区域切换、海洋小船、地点发现、洞窟深入、霸主战与奖励、
地图标记/走路/传送、存档往返、图鉴、战斗平衡。
